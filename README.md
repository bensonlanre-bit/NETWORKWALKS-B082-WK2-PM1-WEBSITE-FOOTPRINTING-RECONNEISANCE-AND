FOOTINGPRINTING, RECONNAISSSANCE AND NETWORK SCANNING

PROECT OVERVIEW

This project demonstrates practical defensive cybersecurity techniques using Kali Linux. It covers footprinting, reconnaissance, network discovery, port scanning and security analysis in an authorised laboratory environment.

OBJECTIVES

- Understand cybersecurity footprinting.
- Perform passive reconnaissance.
- Examine DNS and domain information.
- Discover devices on a controlled network.
- Identify open ports and running services.
- Analyse network security risks.
- Recommend defensive security measures.

TOOLS AND TECHLNOLOGIES

- Kali Linux
- Nmap
- WHOIS
- DIG
- Wireshark
- GitHub

PROJECT MODULES

1. Footprinting
2. Passive Reconnaissance
3. DNS Enumeration
4. Network Discovery
5. Port Scanning
6. Service and Version Detection
7. Security Analysis
8. Recommendations and Remediation

LAB ENVIRONMENT

All active scanning activities will be conducted against systems owned by me or explicitly authorised for testing.

EXPECTED OUTCOME

- Practical understanding of network reconnaissance.
- Ability to identify open ports and services.
- Improved network security analysis skills.
- Documented cybersecurity laboratory experience.
